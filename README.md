# esp32-lab

Laboratório de experimentos com ESP32, documentando minha jornada de aprendizado
em C/embarcados, com apoio de IA.

## Sobre

Este repositório reúne pequenos experimentos feitos com ESP32 (simulados no Wokwi
ou rodando na placa física), organizados por blocos de aprendizado.

## Estrutura

Os experimentos são organizados em pastas numeradas, conforme a trilha de estudo.
A estrutura vai sendo criada conforme os experimentos avançam.

## Como navegar

Cada pasta de experimento tem seu próprio `README.md` explicando o que ele faz
e o que foi aprendido.
